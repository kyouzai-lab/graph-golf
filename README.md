# グラフ・ゴルフ（最小版）

算数6年「比例と反比例」のまとめに使う。方眼の上のカップの座標を目盛りから読んで、比例は y ＝ □ × x、反比例は y ＝ □ ÷ x の □ を入れて打つ。

- 入口：`index.html`（ビルドなし・外部ライブラリなし・外部への通信なし）
- ステージ：`js/stages.js` の `COURSES`（prop＝比例・inv＝反比例）を足す・変えるだけ（カップは整数の交点。答え＝比例は y÷x、反比例は x×y）。ランダムコースは `randomStages()`
- 記録：localStorage のキー `graph-golf-v1` に、コースごとの `reached`・`stars` と、ランダムのいちばんよい合計 `random` だけ
- コースの描画：`js/graph.js`（SVG。大きさが変わるたびに描き直す）
- 画面の流れ：`js/main.js`／見た目：`css/style.css`

## 指示書（2026-11-24）からの決めごと

相談して決めたこと：

- 見た目は A「パターゴルフ場」（芝のグリーン・白い方眼・赤い旗・木の枠）。決定ボタンの文字は「うつ！」
- x と y の1目もりは同じ長さ（正方形の方眼）。そのためコースは縦長になり、縦向きでもコースと入力を左右に並べる（2026-11-24 ゆぐの希望）
- y の目盛りの数字は1ごと（はじめは2ごとだったが、ホール7の y＝3 が読めないという点検の指摘で変更）
- 「つづきから」は、★0 で次へ進んだ面も飛ばして「進んだ先から」。10面のあとは★の合計を出す
- ★は面ごとに「いちばんよい★」を残す。「はじめから」は進み具合だけ1面に戻す（★は消えない）。★を消すのは「きろくをけす」だけ

点検（2026-11-24）を受けて足したこと：

- 反比例コース（タイトルで「比例」「反比例」を選ぶ。進み具合と★はコースごと）。ボールは上の端から曲線にそって右下へ転がる
- ランダムコース（比例・反比例それぞれ。毎回ちがう10ホール。比例の □ は 0.5きざみで 0.5〜10、反比例の □ は 4〜60 で y≧2。x≧2・同じカップなし・同じ □ は2回まで）。いちばんよい★の合計を残す
- 2打目を外したら手がかりを光らせる。比例は x＝1 の縦の帯（「x＝1 のとき y は いくつ？」）、反比例は原点からカップまでの長方形（「ます目は いくつ？」）
- おわりの画面に日付を出す。名前欄は入れない（ゆぐの判断・指示書どおり）
- 入れなかった提案：はずれたときの数の一言、あそびかた、小数の前の一言、初めてのときの「つづきから」

Claude が決めたこと（変えてよい）：

- 外れたら入力は空にもどす（外れた線のそばに、入れた数をうすく書く）
- 面が終わったら（クリアでも3回外れでも）、カップから軸への点線・座標・「y÷x＝□」・式を出す。3回外れのときは答えの線も点線で出す
- 1回目のクリアは「ホールインワン！」
- 入力は4文字まで（例：12.5）
